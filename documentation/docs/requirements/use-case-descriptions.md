### Use Case: Add a team to the watch list.
**Primary Actor:** Sports Fan

**Goal:** Choose which teams’ scores should be hidden until the fan has watched the game.

**User Story:** I never miss a 76ers game but can't always watch live due to work and travel.  I'd like a watch-list to track upcoming games and hide scores until I’m ready to view them.

**Triggering event:** The fan opens the extension popup and adds "Philadelphia 76ers."

**Preconditions:** 
- The extension is installed and enabled.
- A schedule (fresh or cached) is available so the team's list of games can be shown.

**Normal flow:**
1. The fan opens the extension popup.
2. The system displays the popup dashboard, with a status bar message displaying which sites are compatible, for example: "StopSpoiling blocks scores on ESPN".
3. The fan clicks "Add a team to your watch-list."
4. The system displays the supported leagues (currently NBA) and their teams. 
5. The fan selects "NBA" > "76ers" > "Add Team".  Selecting multiple teams is possible.
6. The system saves the selected teams to extension storage. 
7. The system updates the dashboard to show all selected teams and previous/next games. 
8. The system applies blurring to open tabs on supported websites for those teams’ games.

**Alternate flows:**

**2a** - First use, empty watch-list: The dashboard shows an empty state prompting the fan to add a team.  
**5a** - Team already on the watch-list: The system marks it as already added and does not create a duplicate.  
**5b** - Fan selects no teams and closes the popup: Nothing is saved and the watch-list is unchanged.  
**7a** - Schedule cannot be loaded and no cached copy exists: The system shows the “Spoilers Ahead!” warning.

**Postconditions:**

- Selected teams are stored in extension storage by team IDs only.
- The dashboard lists the teams.
- Scores for those teams’ unwatched games are blurred on supported sites.
